# 午夜书斋 / ChatFiles —— 复刻文档包

把一台电脑里**你自己**的微信（+ QQ）聊天记录与文件，解密、解析、AI 提炼，做成一个本地可浏览的「第二大脑」网站（端口 **3456**）。本文档包让其他人带着**提示词 + 规格**，用**自己的**数据复刻出同款项目——除你自己的私有聊天/媒体内容外，**其余功能一模一样可复刻**。

> 本项目是「通用模板」：下文用本人项目（机主"羽升"，华中科技大学基础医学强基 2501）的真实数据与数字作为**范例与默认值**；所有与机器/账号相关的值都用 `{{占位符}}` 标出，复刻者替换为自己的即可。

## 这套文档怎么用

| 路径 | 适合 | 怎么做 |
|---|---|---|
| **A. 一键喂给 AI** | 让 AI 编程助手（Claude Code / Codex）自动复刻 | 打开 [`docs/PROMPT.md`](docs/PROMPT.md)，改好占位符，把 **Mega-Prompt** 粘给 Claude Code（带 `ultracode`）。AI 会按 [`docs/spec/`](docs/spec/00_overview.md) 自动建。 |
| **B. 工程师手动复刻** | 想一步步搭、看懂每个细节 | 按 [`docs/RUNBOOK.md`](docs/RUNBOOK.md) 的 Phase 0→8 操作，遇到「为什么」查 [`docs/spec/`](docs/spec/00_overview.md)。 |

无论哪条路径，都建议先读 [`AGENTS.md`](AGENTS.md)（项目宪法）与 [`docs/SKILLS.md`](docs/SKILLS.md)（用到的 Claude Code skills / 能力）——这是"做出同款质量"的关键。

## 最终形态（本项目实测）

一个 React + TypeScript 网站（Express 服务，端口 3456），左侧两组导航——**成果**（概览/聊天/文件/洞察/学业/媒体）+ **配置**（总结/线索/聊天整理/数据库/候选/知识/AI）：

| 板块 | 内容（本项目实测规模） |
|---|---|
| **概览** | 980 会话 · 738,511 消息 · 18,068 联系人 · 5,907 文件 |
| **聊天** | 全部会话按人/群浏览，真实气泡、日期分隔、会话内搜索、下滑懒加载、右栏「AI 解析」 |
| **文件** | 5,907 份有价值文件归类（学业/比赛/AI/创业/专业…），VS Code 树 + 右侧多格式渲染、去重 |
| **洞察** | 2,338 条提炼要点 + 464 篇会话总结 + 13 篇主题富文本总结 |
| **学业** | 课程/资料板块（可接学校教务站点） |
| **AI** | 接入任意 OpenAI 兼容接口，聊天里对单会话全文做 AI 解析（阈值 1 万–80 万 token） |

审美：**「午夜书斋 / Midnight Study」**——温暖深色编辑风（金 `#d8a24a` / 玉 `#79a99a` / 锈 `#c0653a`，衬线 Fraunces + 无衬线 Hanken Grotesk + 等宽 JetBrains Mono + CJK 字体栈）。

## ⚠️ 安全红线（必须遵守 / 一字不改地传达给 AI）

1. **只解密你自己的、你拥有的数据**——"对自己设备上自己聊天数据的本地备份/归档"。**不要**用于他人数据、未授权设备或任何监控/窃取用途。
2. **绝不删除、移动、改写任何原始聊天记录或文件**。全程只对**副本**操作：解密只读原始库、明文写到 `work/decrypted/`；归档只**复制**到 `archive/`，原文件原封不动。
3. **不上传**。所有处理本地完成；不要把数据库、密钥或聊天内容传到任何外部服务。AI 助手的密钥只存浏览器、经本机代理透传、服务端不落盘。
4. **不运行来路不明的二进制**。工具链（Go / mingw / 自写 crackv4）均官方下载、本地编译、源码可审计。
5. **边界要诚实**：能解的解，解不了的（如 QQ 正文）如实记录为边界，不要伪造或绕过安全限制。
6. **隐私不进仓库**：`.gitignore` 排除一切个人内容产物，仓库只突出代码框架 + 本文档包。

> 法务/合规：解密本人微信本地数据用于个人归档在多数司法辖区属个人数据可携权范畴；但请自行确认所在地法律与平台条款。本文档不构成法律建议。
