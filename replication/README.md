# ChatFiles replication

这是 ChatFiles 的可复刻代码与文档入口，不包含任何私人聊天、数据库、媒体或密钥。

先读：

1. [`docs/spec/01_architecture.md`](docs/spec/01_architecture.md)：唯一权威的架构、字段、关系、能力与激活规范。
2. [`docs/RUNBOOK.md`](docs/RUNBOOK.md)：补充操作顺序。
3. [`docs/PROMPT.md`](docs/PROMPT.md)：给实现 Agent 的补充提示。
4. [`AGENTS.md`](AGENTS.md)：安全红线与阶段提交规则。

所有本机路径、账号、昵称和数据规模都应由本地配置或数据产品 receipt 提供，不能硬编码进 replication 文档。
