# PROMPT · 复刻提示词（喂给 AI 一键复刻）

把下面的 **Mega-Prompt** 复制出来、替换 `{{占位符}}`，在 **Claude Code**（或 Codex）里粘贴发送即可。开头的 `ultracode` 是触发词——它让 AI 启用多 agent Workflow 编排（大规模并行提炼/综述靠它）。

> 前提：① 微信（QQ）**正在运行且已登录**（内存取密钥的硬前提）；② 装好 Node 24+、Python 3.14、git，可联网（详见 [`RUNBOOK.md`](RUNBOOK.md) Phase 0）。
> 占位符速查：`{{项目目录}}`=网站根目录、`{{微信数据根}}`=微信存储根（默认 `C:\Users\<你>\xwechat_files`，**可能被迁到别处**）、`{{一级分类}}`=你的顶级文件夹、`{{身份}}`、`{{学业站点}}`=要接入的课程站点（没有就删那句）。

---

## A. 一键 Mega-Prompt（推荐）

```text
ultracode 我要做一个本地的"第二大脑"网站，深度系统地把我自己微信（和 QQ）里的全部聊天记录与有价值文件解密、整理出来。请你设法找到我电脑上微信/QQ 聊天记录和文件的真实存储位置，然后用 React + TypeScript、最适合富文本/多格式的架构，做一个端口 3456 的网站，项目目录在 "{{项目目录}}"。

网站要做到：
1. 文件板块：把微信/QQ 里所有有价值的文件复制进项目并做好顶级分类（一级分类如 {{一级分类：过去/创业/AI/树林/学业/专业/比赛 等}}，次级自己延伸）。同名文件 xxx、xxx(1)、xxx(2) 取序号最大；内容相同(sha256)只留一份。用类似 VS Code 的文件夹树浏览，点击后右侧把所有常见格式（图片/视频/语音/PDF/Word/Excel/PPT/Markdown/代码/网页/压缩包/数据库结构…）完美内部渲染。
2. 聊天板块：解密并解析我**全部**微信聊天记录，按人物/群组浏览，真实气泡、日期分隔、会话内搜索。
3. 洞察/总结板块：从所有聊天里提炼——(a) 技术/哲理上有价值的内容，按群/人归类；(b) 我学业能用的资料（我是 {{身份，如 基医强基 2501}}，下学期要学 {{学业站点}} 的内容）；(c) 其他一切有价值内容。并**自己生成顶级富文本总结**：按主题做成可随时回看的文档。板块可自己延伸（资源工具/人物/个人成长…）。

关键体验与新功能：
4. 海量内容必须动态懒加载：聊天、文件夹树、媒体网格等先加载有限数量，下滑再懒加载续载，较远上方不再渲染（虚拟化/content-visibility），严防卡死。
5. 三栏/多栏板块（如总结）左、中、右各自独立滚动，不能一起滚导致左栏被带走。
6. 左侧导航分两组：上半"成果"（概览/聊天/文件/洞察/学业/媒体），下半"配置"（总结/线索/聊天整理/数据库/候选/知识/AI）。
7. AI 板块（AI 功能，很关键）：在设置页可配置接口 URL、API Key、模型 ID 等基础参数；随后在聊天板块右侧面板新增「AI 解析」，点击以悬浮窗形式与 AI 对话，AI 能读取该聊天的全部上下文（注入式）；用户可把上下文阈值从 1 万 token 调到 80 万 token；当实际上下文长于阈值（模型可承载上下文）时必须报错。密钥只存本机浏览器、经本机代理透传、不落盘。

硬约束（务必遵守）：
- **禁止删除/移动/改写任何原始聊天记录与文件**；只读原始、只对副本解密、只复制文件到项目里。只解密我自己的本地数据。不上传。
- 一切用最顶尖方式；**审美设计必须结合 frontend-design skill**；保持项目架构规范、单文件不超过约 300 行、不堆砌冗余代码。
- 目标：直到全部弄完（所有文件归类、所有微信聊天都探索并深度整理），或你确实无法操作再停。
- 必须探索所有目录下的微信/QQ 数据，不要把平台日志/缓存/广告当成我的聊天正文。
- 遵守 PADC（规划-分析-实现-提交）流程，每完成一个阶段就 commit；不清楚的地方自己分析后选最佳方案。

请先深度勘探现状（已有什么、数据在哪、能否解密），把关键发现告诉我，再开始建。遇到"解密方式"和"前端改造范围"这类需要我拍板的，用 AskUserQuestion 问我。
```

> 这条提示词复刻了本项目的完整意图与全部硬约束（含本轮新增的 AI 解析、懒加载、独立滚动、导航分组）。AI 收到后会先勘探、在两处征询你（见 C 节），再自建工具链解密、解析、归档、用多 agent 提炼、用 frontend-design 做前端。

## B. 分阶段提示词（想分步把控时用）

逐条发送，每条等 AI 做完再发下一条：

1. **勘探**：`ultracode 勘探我电脑上微信/QQ 聊天记录与文件的真实存储位置和可解密性：微信 4.0(xwechat_files\<wxid>\db_storage) 与 QQ NT(nt_qq\nt_db) 的库在哪、是否加密、进程是否在运行。整理给我，先别动手。`
2. **解密**：`搭建解密工具链并解密我的微信库（只对副本操作，绝不碰原始文件）。现成工具在新版常失效时，用"从运行进程内存恢复每个库的派生密钥 + 便宜校验"的版本无关方法。解密后用 Python 验证能读到真实中文消息。`
3. **解析**：`把解密库解析成一个明文 SQLite(conversations/messages/contacts 三表)，正文 zstd 解压、发送人用 name2id 还原、按类型映射。统计会话/消息数给我。`
4. **归档**：`把有价值文件复制进项目并按 {{一级分类}} 归类，同名取最大序号 + sha256 去重，跳过加密 .dat 与缓存噪声。原文件不动。`
5. **提炼**：`ultracode 对每个有实质内容的会话，用多 agent 并行提炼有长期价值的要点，写成结构化 JSON；再按类综述成富文本总结板。`
6. **前端**：`用 frontend-design skill 做一个深色编辑风站点，端口 3456，导航分成果/配置两组；保留多格式预览引擎；海量列表懒加载、三栏独立滚动。build 通过并端到端核验。`
7. **AI 解析**：`新增 AI 板块（配置 URL/Key/模型/阈值，密钥仅存浏览器、经本机代理透传不落盘）；聊天右栏加「AI 解析」悬浮窗，注入该会话全文、阈值 1 万–80 万 token、超阈值报错。`

## C. 两个决策点（AI 会用 AskUserQuestion 问你）

| 决策 | 选项 | 本项目的选择 / 建议 |
|---|---|---|
| **解密方式** | 自写可审计脚本 / 成熟开源工具 / 两者结合 | 本项目"先试成熟工具"，但新版微信 4.1.9.x 上现成工具失效、相关仓库被下架，最终落到**自写的版本无关派生密钥扫描**（见 [`spec/03_decryption.md`](spec/03_decryption.md)）。建议答"两者结合：先试成熟工具，失效就自写"。 |
| **前端改造范围** | 重做前端 + 全部新板块 / 在现有界面扩展 / 整站重写 | 本项目选**重做前端 + 全部新板块**（保留可用服务端与预览引擎）。推荐同款。 |
