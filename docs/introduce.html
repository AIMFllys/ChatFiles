面向零基础

新手教程：从零跑出这个项目

跟着 5 步走。每一步都给了能直接复制的命令；不懂的名词都有"小白解释"。

安装「凯杰」开源的 skills 技能包

这个项目的"超能力"（多 agent 并行、frontend-design 审美、Workflow 编排）来自一套开源 skills。先把它装进 Claude Code。

还没装 Claude Code？ 先按 UU 整理的图文教程一步步配置好，再回来装 skills：
📘 UU 的 Claude Code 安装配置教程（飞书）→

小白解释：「skills / 技能包」就像给 AI 装的插件，装好后它才会用那些高级能力。按「凯杰」skills 仓库 / 教程里的说明安装即可。

新建一个文件夹，放入几份规范文件

在你电脑上随便建一个空文件夹（比如 D:\ChatFiles），把本项目 replication/ 整个复制进去（AGENTS.md、README.md、global.css 和 docs/，尤其 docs/PROMPT.md 与 docs/spec/）。AI 会读它们当作"施工图"。

你的新文件夹
D:\ChatFiles\
└─ replication\
   ├─ AGENTS.md          # 项目宪法（AI 必读）
   ├─ README.md          # 导航
   ├─ global.css         # 设计基座
   └─ docs\
      ├─ PROMPT.md       # ← 待会儿复制里面的提示词
      ├─ RUNBOOK.md      # 逐步手册
      ├─ SKILLS.md
      └─ spec\           # ← 完整技术规格，AI 照这建

打开 Claude Code，cd 进这个文件夹

打开 Claude Code（或终端里输入 claude），然后让它"进入"你刚建的文件夹。

terminal — claude code
cd D:\ChatFiles

小白解释：cd = "change directory / 进入文件夹"。怎么拿到路径？在文件资源管理器里打开那个文件夹，点一下顶部地址栏 → 全选复制，把它接在 cd 后面即可。Windows 用 \，macOS 用 /。

用 /goal + 提示词，发送！

第 4 步要粘贴的内容

复刻提示词

把 {{占位符}} 换成你自己的值，整段复制，用 /goal 发送。开头的 ultracode 是触发词——它让 AI 启用多 agent 编排（大规模提炼靠它）。完整版（含 AI 解析 / 懒加载 / 独立滚动 / 导航分组等新功能）与分阶段版见 replication/docs/PROMPT.md。

replication / docs / PROMPT.md — Mega-Prompt 
ultracode 我要做一个本地的"第二大脑"网站，深度系统地把我自己微信（和 QQ）里的全部聊天记录与有价值文件解密、整理出来。请你设法找到我电脑上微信/QQ 聊天记录和文件的真实存储位置，然后用 React + TypeScript、最适合富文本/多格式的架构，做一个端口 3456 的网站，项目目录在 "{{项目目录}}"。

网站要做到：
1. 文件板块：把微信/QQ 里所有有价值的文件，复制进项目目录并做好顶级分类（一级分类如 {{一级分类：过去/创业/AI/树林/学业/专业/比赛 等}}，次级、次次级自己延伸）。同名文件如 xxx、xxx(1)、xxx(2) 取序号最大的一份，内容相同(sha256)只留一份。用类似 VS Code 文件夹树的形式浏览，点击后右侧把所有常见格式（图片/视频/语音/PDF/Word/Excel/PPT/Markdown/代码/网页/压缩包/数据库结构…）完美内部渲染。
2. 聊天板块：解密并解析我全部微信聊天记录，按人物/群组可浏览。
3. 洞察/总结板块：从所有聊天记录里提炼——(a) 技术上有价值、哲理上有价值的内容，按聊群/人物归类；(b) 我学业上能用的资料（我是 {{你的身份，如 基医强基 2501}}，下学期要学 {{学业站点}} 的内容）；(c) 其他一切有价值的内容。并且自己生成顶级富文本总结：总结每段聊天、提炼关键信息，做成可随时回看的主题文档。板块自己延伸（如 资源工具/人物/个人成长 等）。

关键体验与新功能：
4. 海量内容动态懒加载：聊天、文件夹树、媒体网格先加载有限数量，下滑再懒加载续载，较远上方不再渲染，严防卡死。
5. 三栏/多栏板块（如总结）左、中、右各自独立滚动，不能一起滚导致左栏被带走。
6. 左侧导航分两组：上半成果组（概览/聊天/文件/洞察/学业/媒体），下半配置组（总结/线索/聊天整理/数据库/候选/知识/AI）。
7. AI 板块：设置页可配置接口 URL、API Key、模型 ID、上下文阈值；聊天右侧面板加「AI 解析」悬浮窗，AI 读取该会话全部上下文（注入式），阈值可从 1 万 token 调到 80 万 token，实际上下文超过阈值要报错。密钥只存本机浏览器、经本机代理透传、不落盘。

硬约束（务必遵守）：
- 禁止删除/移动/改写任何原始聊天记录与文件；只读原始数据，只对副本解密，只复制文件到项目里。只解密我自己的本地数据。不上传。
- 一切用最顶尖方式；审美设计必须结合 frontend-design skill；保持架构规范、单文件不超过约 300 行、不堆砌冗余代码。
- 遵守 PADC 流程，每完成一个阶段就 commit；不清楚的地方自己分析后选最佳方案。
- 目标：直到全部弄完（所有文件归类、所有微信聊天记录都探索并深度整理），或你确实无法操作再停。
- 必须探索所有目录下的微信/QQ 数据，不要把平台日志/缓存/广告当成我的聊天正文。

请先深度勘探现状（已有什么、数据在哪、能否解密），把关键发现告诉我，再开始建。遇到"解密方式"和"前端改造范围"这类需要我拍板的，用 AskUserQuestion 问我。
