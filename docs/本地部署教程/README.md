# 本地部署教程 · 把克隆下来的空壳，灌入你自己的数据

> 历史部署材料：不得作为现行架构或接口规范。请先阅读 [`replication/docs/spec/01_architecture.md`](../../replication/docs/spec/01_architecture.md)。

> 这套 Spec 文档面向**已经 `git clone` 了本仓库**的你（或你的 AI agent）。仓库里有完整的代码框架，但**没有任何聊天记录、媒体、洞察**——它是一个空壳。本教程指导 AI **在你本机自主搜索**你自己的微信 / QQ 数据，解密、解析、归档、提炼，把空壳灌满，最后跑起来。
>
> 关键词遵循 **RFC 2119**：MUST / MUST NOT / SHOULD / MAY。中文「必须 / 禁止 / 应当 / 可以」与之等义。

## 这套文档和 `replication/` 有什么不同？

| | `replication/`（仓库根） | `docs/本地部署教程/`（本文件夹） |
|---|---|---|
| **前提** | 一个**空目录**，你想从零**重建整套代码** | 你**已经 clone 了本仓库**，代码现成 |
| **AI 要做的事** | 按 12 篇规格**写代码 + 跑数据管线** | **复用现成代码**，只跑数据管线灌数据 |
| **产物** | 把项目本身造出来 | 把**你的数据**灌进已有项目并跑起来 |
| **深度** | 完整工程规格（解密内核、API、前端…） | 部署导向，深技术细节**引用** `replication/docs/spec/` |

一句话：**`replication/` 教 AI「怎么造这台机器」，本教程教 AI「怎么用你自己的原料把机器开起来」。** 两者共享同一套安全红线与解密 / 解析 / 归档 / 提炼方法论；本教程在需要深扒细节处直接链到 `replication/docs/spec/`，不重复抄写。

## 安全红线（任何一步都不得逾越，与全项目一致）

- **只读原始、只动副本**：解密**只**写到 `work/decrypted/`，原始库 / 文件只读打开。**禁止**删除、移动、改写任何原始聊天记录或文件。
- **只处理你自己的、你拥有的本地数据**：仅对当前登录账号、本机内存里的运行时密钥做恢复。不得用于他人或未授权设备。
- **不上传**：聊天正文、密钥、原始库都不出本机。唯一可能的出网是你**自行配置**的 AI 接入（洞察提炼 / AI 助手），且密钥不落盘。
- **边界如实记录**：解不了的（如 QQ 正文）就如实标注，**禁止**用平台日志 / 缓存伪造成聊天正文。
- **身份不入仓**：你的 wxid / QQ号 / 昵称 / 学校等只写在 gitignored 的 `.env.local`，绝不提交（见 [`01_环境与克隆.md`](01_环境与克隆.md)）。

> 这些目录始终被 `.gitignore` 排除，永远不会进仓库：`data/`、`archive/`、`work/`、`imports/`、`.env`、`.env.*`（`.env.example` 除外）。
